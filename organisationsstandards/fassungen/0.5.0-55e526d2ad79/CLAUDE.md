# Claude Code Einstieg

Die importierten Regeln gelten sinngemäß für Claude Code. Lies die benötigten Standarddateien ausdrücklich. Prüfe beim ersten Einsatz, ob die Anweisungen tatsächlich geladen wurden. Bei einer Einbindung in ein vorhandenes Projekt wird diese Datei zum tatsächlichen Paketpfad importiert. Bestehende Anweisungen bleiben erhalten.
